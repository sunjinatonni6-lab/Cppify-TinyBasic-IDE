# Cppify — TinyBasic Compiler Studio

Cppify is a browser-based IDE for **TinyBasic**, a small custom programming language. Its compiler is written in C++ and compiled to WebAssembly with Emscripten. The browser runs the actual C++ compiler module; there is no JavaScript compiler fallback and no API/backend is used to compile user programs.

> This project compiles TinyBasic programs. It is not a compiler for the C++ language itself.

## Features

- Preserves the original Cppify dark theme, emerald/cyan palette, editor, console, and stage tabs.
- C++ WebAssembly module runs the lexer, parser, semantic checks, bytecode generator, and stack VM.
- Token visualization and JSON token view.
- Generated bytecode and readable instruction listing.
- Compiler diagnostics for lexical, syntax, semantic, and runtime errors.
- Example programs, clear editor/console, copy bytecode, and download compiler `.wasm`.
- Static site structure suitable for GitHub and Vercel.

## TinyBasic language

```text
// Comments start with two slashes
let x = 10;
let y = 20;
let answer = (x + y) * 2;
print answer;
print answer / 3;
```

Supported statements are `let name = expression;` and `print expression;`. Expressions support integer literals, declared variables, unary minus, `+`, `-`, `*`, `/`, and parentheses. Semicolons are required. Variables cannot be redeclared, and undeclared variable use is rejected.

## 1. Build the C++ compiler to WebAssembly

Install the [Emscripten SDK](https://emscripten.org/docs/getting_started/downloads.html), then activate its environment.

**Windows (Emscripten Command Prompt):**

```bat
build-wasm.bat
```

**macOS / Linux:**

```bash
chmod +x build-wasm.sh
./build-wasm.sh
```

The build generates two files in the project root:

- `compiler.js` — Emscripten JavaScript loader/glue.
- `compiler.wasm` — compiled C++ compiler engine.

**Both generated files are required by the web app.** This workspace does not include generated WASM binaries because Emscripten is not installed in the build environment used to prepare the source. Build them with the SDK and commit both files to your GitHub repository before deploying. The IDE deliberately reports a clear setup error instead of pretending to compile if they are missing.

## 2. Run locally

Serve the project over HTTP (do not open `index.html` as a `file://` URL):

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## 3. Push to GitHub

Create a GitHub repository, then run these commands in the project folder after building the WebAssembly files:

```bash
git init
git add .
git commit -m "Build Cppify TinyBasic compiler IDE"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Replace the example repository URL with your own. Ensure `compiler.js` and `compiler.wasm` are included in the commit.

## 4. Deploy on Vercel

1. Import the GitHub repository in Vercel.
2. Framework preset: **Other**.
3. Build command: leave empty (static site).
4. Output directory: `.` (project root).
5. Deploy.

After deployment, check the browser console/network panel and confirm `compiler.js` and `compiler.wasm` both return HTTP 200. WebAssembly should be served with the `application/wasm` MIME type; Vercel normally serves `.wasm` assets correctly.

## Project files

- `index.html` — preserved Cppify UI structure and theme.
- `styles.css` — custom styling and responsive behavior.
- `app.js` — UI only; calls the actual exported C++ function `runTinyBasic()`.
- `main.cpp` — TinyBasic compiler, bytecode generator, virtual machine, and Emscripten binding.
- `build-wasm.sh` / `build-wasm.bat` — compiler build commands.
- `vercel.json` — static deployment configuration.

## Security and scope

All program compilation and execution happens locally in the browser's WebAssembly sandbox. This project does not send source code to a server. It is an educational compiler with a deliberately small language and integer arithmetic; it is not a production compiler or a full C++ implementation.
